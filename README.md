# SW_TE_fitness
The TE data used in Chapter 2 is used here again. Recidivism data curated by Clarie Tsui (Tsui et al., 2026) in "recidivism.xlsx" was incorporated into the database to assess survival. Survival models are run in the main analysis script "Ch3_analysis_script.R" and used "Survival_Data_Ch3.csv".

The lifetime reproductive success model was run in the main analysis script "Ch3_analysis_script.R" and used "LRS_Data_Ch3.csv".

Finally, the reproductive senescence model incorporated annual helper presence data found in "Sparks_helper_presence.csv" (Sparks et al. 2022), producing our annual reproductive success (ARS) data. However, variance in annual reproductive output varied significantly between male and female birds, leading us to split the analysis between males and females. The data for each model is found in "M_ARS_data_Ch3.csv" and "F_ARS_data_Ch3.csv". They were run in "Ch3_analysis_script.R".

Figures and model summary tables were generated in "Ch3_analysis_script.R".

Recidivsm data source:
Claire Lok Sze Tsui, Michael Briga, Jan Komdeur, Terry Burke, David S Richardson, Hannah L Dugdale, Asynchrony of ageing among traits in a wild bird population, Evolution Letters, 2026;, qrag029, https://doi.org/10.1093/evlett/qrag029

Annual helper presence data source:
Sparks, A.M., Hammers, M., Komdeur, J., Burke, T., Richardson, D.S. and Dugdale, H.L. (2022), Sex-dependent effects of parental age on offspring fitness in a cooperatively breeding bird. Evolution Letters, 6: 438-449. https://doi.org/10.1002/evl3.300
